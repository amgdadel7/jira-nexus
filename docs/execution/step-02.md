## 4. القرارات المعمارية الرئيسية (Key Decisions)
1. **الاعتماد الرسمي لـ `Node.js + PostgreSQL`**: لكونه الخيار الوحيد الذي يجمع بين اكتمال ميزات المنتج بنسبة 100% والالتزام الصارم بمعايير `AI_DEVELOPMENT_RULES.md` المعمارية.
2. **الحفاظ على المسارات القديمة دون شطب فوري**: لضمان عدم حدوث أي فقدان للميزات أو البيانات، مع تمكين المطورين من تشغيل المسار القديم إذا دعت الحاجة عبر `npm run start:legacy`.
3. **توحيد البروكسي على منافذ قياسية**: منفذ الواجهة `5173`، منفذ الواجهة الخلفية `3000`، وربط مسار `/api` نسبياً عبر Vite proxy الداخلي لتفادي مشاكل CORS و localhost في بيئات العمل المشتركة.

## 5. خطة الترحيل والتراجع (Migration & Rollback)
- **إدارة الترحيل**: تم تجهيز البنية التحتية للمسار المعتمد بالكامل (9 ترحيلات SQL جاهزة ومطبقة). عملية نقل السجلات الفعلية من ملف SQLite القديم إلى PostgreSQL مجدولة ومنوطة بالخطوة **03**.
- **إمكانية التراجع**: يمكن الرجوع لتشغيل المسار القديم في أي لحظة عبر تشغيل `npm run start:legacy` دون أي أثر سلبي.

## آلية الاعتماد

- أرسل برومبتاً واحداً فقط في كل مرة.
- راجع التقرير المتوقع في `docs/execution/step-NN.md` والفرق ونتائج الاختبارات قبل إرسال التالي.
- لا تعتبر التقرير وحده إثباتاً؛ راجع أدلة القبول. لا تحذف الاختبارات أو تضعفها لتمرير البوابة.
- المانع الذي يتطلب مالك الخدمة، كتدوير اعتماد خارجي، يبقى معلناً. لا يُتجاوز ضمنياً؛ يمكن استمرار عمل محلي معزول فقط إذا لم يعتمد على المانع وكان ذلك موثقاً.
- لا نقل أو حذف لبيانات إنتاج، ولا نشر أو خدمات مدفوعة، دون تفويض مستقل.
- لا تُحوَّل بيئة إنتاج للمسار الجديد في 02 قبل اعتماد ترحيل 03.

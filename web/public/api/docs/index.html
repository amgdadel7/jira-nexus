Masar REST API Reference

All REST endpoints return JSON. Use this API to programmatically manage projects, issues, sprints, and integrations.

Authentication: Pass Authorization: Bearer <token> in request headers. Tokens are obtained from POST /api/auth/login or personal API tokens generated in Profile settings.

Authentication

GET /api/auth/config Public authentication config & providers 
curl -X GET "https://masar-nexus-workspace.vercel.app/api/auth/config"
POST /api/auth/login Authenticate with email & password 
curl -X POST "https://masar-nexus-workspace.vercel.app/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "user@example.com", "password": "your-password"}'
GET /api/auth/me Get current authenticated user profile 
curl -X GET "https://masar-nexus-workspace.vercel.app/api/auth/me" \
  -H "Authorization: Bearer $TOKEN"

Projects

GET /api/projects List all workspace projects 
curl -X GET "https://masar-nexus-workspace.vercel.app/api/projects" \
  -H "Authorization: Bearer $TOKEN"
GET /api/meta?project=KAN Get project metadata, statuses, and fields 
curl -X GET "https://masar-nexus-workspace.vercel.app/api/meta?project=KAN" \
  -H "Authorization: Bearer $TOKEN"

Work Items (Issues)

GET /api/search?jql=project=KAN Search issues using JQL syntax 
curl -X GET "https://masar-nexus-workspace.vercel.app/api/search?jql=project=KAN" \
  -H "Authorization: Bearer $TOKEN"
POST /api/issues Create a new work item 
curl -X POST "https://masar-nexus-workspace.vercel.app/api/issues" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"projectKey": "KAN", "type": "Task", "summary": "New Issue", "priority": "Medium"}'
GET /api/issues/{key} Get issue details, comments, and attachments 
curl -X GET "https://masar-nexus-workspace.vercel.app/api/issues/KAN-1" \
  -H "Authorization: Bearer $TOKEN"
PATCH /api/comments/{id} Update comment content 
curl -X PATCH "https://masar-nexus-workspace.vercel.app/api/comments/12" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"body": "Updated comment text"}'
DELETE /api/issues/{key} Delete a work item 
curl -X DELETE "https://masar-nexus-workspace.vercel.app/api/issues/KAN-1" \
  -H "Authorization: Bearer $TOKEN"
